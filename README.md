# Blatmetro Browser

**Текущая версия исходного проекта:** 0.4.6  
**Платформа:** Windows 10 x64 и новее  
**Технологии:** C#, WPF, .NET 10, CefSharp, Chromium

Blatmetro Browser — самостоятельный браузер для Windows на базе Chromium через CefSharp. Проект развивается как отдельное приложение; в перспективе отдельные идеи интерфейса и архитектуры могут быть адаптированы для BlatmetroOS.

> Это исходный код версии 0.4.6 для разработки и тестирования, а не подтверждение готовности официального релизного EXE.

## Возможности

- Встроенный движок Chromium через CefSharp.
- Несколько вкладок: создание, переключение и закрытие.
- Адресная строка для URL и поисковых запросов.
- Выбор поисковой системы: DuckDuckGo, Google, Microsoft Bing, Brave Search, Яндекс, Ecosia, Qwant, Startpage, Yahoo, PrivacyWall, Perplexity и @MAIL.RU.
- Закладки с локальным сохранением в JSON.
- Три режима оформления: системный, светлый и тёмный.
- Согласование темы Chromium с настройкой `prefers-color-scheme` для сайтов, которые поддерживают этот стандарт.
- Меню браузера, домашняя страница и панель закладок.
- Управление масштабом страницы.
- Полноэкранный режим и управление размером окна.
- Страница загрузок с отображением прогресса, состояния и действиями для загрузок.
- Открытие всплывающих веб-окон в новых вкладках.
- Горячие клавиши: `Ctrl+T`, `Ctrl+W`, `Ctrl+L`, `Ctrl+R`, `Ctrl+Tab`, `Ctrl+Shift+Tab`, `F5`, `F11`, `Esc`.

## Требования

- Windows 10 x64 или новее.
- .NET 10 SDK (не только Runtime).
- Интернет для первоначального восстановления NuGet-пакетов.

Проект собирается для Windows x64. Встроенный Chromium увеличивает размер приложения и расход памяти; на компьютерах с 4 ГБ ОЗУ браузер может работать заметно тяжелее небольших приложений.

## Сборка и запуск из исходников

1. Установите .NET 10 SDK.
2. Склонируйте репозиторий или скачайте исходный код.
3. Откройте папку проекта.
4. Запустите `run.cmd` для запуска или `build.cmd` для сборки.

Команды PowerShell из папки проекта:

```powershell
dotnet restore .\BlatmetroBrowser.csproj -r win-x64
dotnet build .\BlatmetroBrowser.csproj -c Release
dotnet run --project .\BlatmetroBrowser.csproj -c Release
```

## Хранение данных

- Профиль Chromium и кэш: `%LOCALAPPDATA%\Blatmetro\Browser`.
- Закладки и настройки: `%APPDATA%\Blatmetro\Browser`.
- Диагностический журнал CEF: `%LOCALAPPDATA%\Blatmetro\Browser\cef.log`.

Список загрузок в текущей реализации хранится в памяти приложения и не является постоянной историей загрузок.

## Приватность и сетевые функции

В конфигурации Chromium отключены некоторые необязательные фоновые функции, включая фоновую сетевую активность, компонентные обновления и синхронизацию. Это не означает полного отсутствия телеметрии или сетевых обращений: сайты и сам браузер могут выполнять необходимые сетевые запросы. Для оценки сетевого поведения нужны отдельные тесты.

## Сторонние компоненты и лицензии

Браузер использует CefSharp и Chromium Embedded Framework (CEF), основанный на Chromium. Перед распространением собранного приложения необходимо включить применимые лицензии и уведомления для CefSharp, CEF, Chromium и других распространяемых компонентов.

- [CefSharp](https://github.com/cefsharp/CefSharp)
- [Chromium Embedded Framework](https://github.com/chromiumembedded/cef)
- [CefSharp.Wpf.NETCore на NuGet](https://www.nuget.org/packages/CefSharp.Wpf.NETCore/154.0.340)

Информация о лицензиях Chromium/CEF доступна в самом движке на страницах `about:license` и `about:credits`, если они поддерживаются используемой сборкой.
