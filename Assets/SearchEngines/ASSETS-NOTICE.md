# Search engine icon assets

The Google, DuckDuckGo, Brave, Ecosia, Qwant, Startpage, Perplexity, and Mail.Ru vector marks are based on Simple Icons project artwork (https://simpleicons.org/), available under CC0 1.0 Universal.

The Yandex, Microsoft Bing, Yahoo, and PrivacyWall marks included here are simplified local UI marks created for the selector because a matching Simple Icons mark was not available in the selected icon set.
