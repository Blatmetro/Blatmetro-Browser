# Third-party notices

Blatmetro Browser embeds CefSharp, Chromium Embedded Framework (CEF), and Chromium through the `CefSharp.Wpf.NETCore` NuGet package.

These are separate open-source projects with their own license and attribution requirements. This source archive does not bundle the Chromium runtime binaries. Before distributing a compiled installer or application, include the license texts and notices shipped with the exact NuGet/CEF binary packages used for that build.

Project references:
- CefSharp: https://github.com/cefsharp/CefSharp
- CEF: https://github.com/chromiumembedded/cef
- Chromium: https://www.chromium.org/Home/chromium-terms/
